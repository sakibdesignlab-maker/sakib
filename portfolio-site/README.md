# আপনার পোর্টফোলিও ওয়েবসাইট — সেটআপ গাইড

এই ফোল্ডারে আপনার সম্পূর্ণ ওয়েবসাইট আছে: হোমপেজ, ক্যাটাগরি সেকশন, পোর্টফোলিও গ্রিড, WhatsApp কন্টাক্ট বাটন, আর একটা এডমিন প্যানেল যেখান থেকে নতুন কাজ (ছবি) আপলোড করতে পারবেন।

## ধাপ ১: নিজের তথ্য বসান

`js/main.js` ফাইলটা খুলুন, একদম উপরে `CONFIG` অংশে এগুলো বদলে দিন:
- `name` — আপনার নাম / ব্র্যান্ডের নাম
- `whatsappNumber` — দেশের কোড সহ, `+` বা শুরুর `0` ছাড়া। যেমন বাংলাদেশের নাম্বার `01712345678` হলে লিখবেন `8801712345678`
- `email` — আপনার ইমেইল
- `bio`, `tagline` — আপনার সম্পর্কে ছোট বিবরণ

## ধাপ ২: GitHub-এ কোড আপলোড করুন

এডমিন প্যানেল (নতুন কাজ আপলোড করার সিস্টেম) কাজ করার জন্য কোডটা GitHub-এ থাকতে হবে।

1. [github.com](https://github.com)-এ একটা ফ্রি অ্যাকাউন্ট বানান (না থাকলে)
2. একটা নতুন **repository** বানান (যেমন নাম: `my-portfolio`)
3. এই পুরো ফোল্ডারের সব ফাইল সেই repository-তে আপলোড করুন (GitHub ওয়েবসাইট থেকে "uploading an existing file" অপশন দিয়েও করা যায়, কোনো কমান্ড লাইনের দরকার নেই)

## ধাপ ৩: Netlify দিয়ে ফ্রি হোস্ট করুন

1. [netlify.com](https://netlify.com)-এ ফ্রি অ্যাকাউন্ট বানান (GitHub দিয়ে সাইন আপ করলে সহজ হবে)
2. **"Add new site" → "Import an existing project"** এ ক্লিক করুন
3. GitHub সিলেক্ট করে আপনার `my-portfolio` repository বেছে নিন
4. Build সেটিংস খালি রাখুন (কোনো build command লাগবে না, publish directory `/` রাখুন) এবং **Deploy** করুন
5. কিছুক্ষণের মধ্যেই আপনার সাইট লাইভ হয়ে যাবে একটা ফ্রি ঠিকানায়, যেমন: `your-site-name.netlify.app`
   - Netlify-র সাইট সেটিংস থেকে "Change site name" দিয়ে এই ঠিকানাটা নিজের পছন্দমতো (যেমন `rahim-designs.netlify.app`) করে নিতে পারবেন

## ধাপ ৪: এডমিন প্যানেল চালু করুন (Identity + Git Gateway)

এটা একবার সেট করলেই আপনি যেকোনো সময় ব্রাউজার থেকে নতুন কাজ আপলোড করতে পারবেন, কোনো কোড না ছুঁয়ে।

1. Netlify সাইটের **Site configuration → Identity** এ যান, **"Enable Identity"** ক্লিক করুন
2. Identity সেটিংসে **"Registration"** অংশে **"Invite only"** সিলেক্ট করুন (যাতে অন্য কেউ সাইন আপ করে এডমিন প্যানেলে ঢুকতে না পারে)
3. একই পেজে নিচে **"Services" → "Git Gateway"** অংশে গিয়ে **"Enable Git Gateway"** ক্লিক করুন
4. **Identity** ট্যাব থেকে **"Invite users"** দিয়ে নিজের ইমেইলে একটা invite পাঠান
5. ইমেইলে আসা লিংকে ক্লিক করে পাসওয়ার্ড সেট করুন

এরপর থেকে `your-site-name.netlify.app/admin` এ গিয়ে লগইন করলেই একটা সহজ ড্যাশবোর্ড পাবেন — সেখান থেকে "কাজসমূহ" এ ক্লিক করে নতুন কাজ যোগ করতে পারবেন (শিরোনাম, ক্যাটাগরি বেছে নেওয়া, ছবি আপলোড, বিবরণ) — Save/Publish করলেই ওয়েবসাইটে স্বয়ংক্রিয়ভাবে যোগ হয়ে যাবে (আপডেট হতে ১-২ মিনিট লাগতে পারে)।

## নতুন কাজ (portfolio item) যোগ করা

`your-site-name.netlify.app/admin` এ লগইন করুন → **"পোর্টফোলিও কাজ"** → **"সব কাজের তালিকা"** → নতুন আইটেম যোগ করুন → শিরোনাম, ক্যাটাগরি আইডি, ছবি, বিবরণ দিন → Publish করুন।

## নতুন ক্যাটাগরি/সেকশন যোগ করা (কোনো কোডের দরকার নেই)

হোমপেজে যে ৪টা ক্যাটাগরি (লোগো ডিজাইন, ব্যানার ডিজাইন ইত্যাদি) দেখছেন, সেগুলো ফিক্সড নয় — আপনি নিজেই এডমিন প্যানেল থেকে যত ইচ্ছা নতুন ক্যাটাগরি যোগ করতে বা মুছতে পারবেন, ঠিক যেভাবে Google Drive এ নতুন ফোল্ডার বানান।

1. `/admin` এ লগইন করুন
2. বাম পাশের মেনু থেকে **"ক্যাটাগরি (সেকশন)"** এ ক্লিক করুন, তারপর **"সব ক্যাটাগরির তালিকা"**
3. **"আইটেম যোগ করুন"** চাপুন
4. দুটো ঘর পূরণ করুন:
   - **আইডি** — শুধু ইংরেজি ছোট হাতের অক্ষরে, স্পেস ছাড়া, যেমন: `photo-editing` বা `packaging-design`
   - **নাম** — এটাই ওয়েবসাইটে দেখাবে, যেমন: `ফটো এডিটিং`
5. Publish করুন — সাথে সাথে হোমপেজে নতুন একটা স্টিকার/ক্যাটাগরি যোগ হয়ে যাবে

এরপর নতুন কাজ যোগ করার সময় "ক্যাটাগরি আইডি" ঘরে ঠিক সেই আইডিটাই লিখুন (যেমন `photo-editing`) যাতে কাজটা সঠিক ক্যাটাগরিতে দেখা যায়।

> **মনে রাখবেন:** আইডি আর নাম — দুটো আলাদা জিনিস। "নাম" যেকোনো ভাষায় (বাংলা/ইংরেজি) যা খুশি লিখতে পারেন, কিন্তু "আইডি" সবসময় সহজ ইংরেজি অক্ষরে রাখবেন এবং কাজ যোগ করার সময় হুবহু সেটাই ব্যবহার করবেন।

## নমুনা কাজগুলো মুছে ফেলুন

সাইটে এখন ৪টা নমুনা (sample) কাজ আছে — একটা প্রতিটা ক্যাটাগরির জন্য। এডমিন প্যানেল থেকে লগইন করে নিজের আসল কাজ যোগ করার পর এই নমুনাগুলো মুছে দিন।

## পরে নিজের ডোমেইন (যেমন .com) চাইলে

Netlify-র ফ্রি সাবডোমেইন (`.netlify.app`) স্থায়ীভাবে ফ্রি এবং কাজ চালানোর জন্য যথেষ্ট। ভবিষ্যতে চাইলে যেকোনো ডোমেইন রেজিস্ট্রার (Namecheap, GoDaddy ইত্যাদি) থেকে একটা `.com`/`.xyz` ডোমেইন কিনে Netlify সাইট সেটিংস থেকে "Add custom domain" দিয়ে যুক্ত করে নেওয়া যাবে — কোনো কোড বদলাতে হবে না।

## ফাইল স্ট্রাকচার

```
index.html          → মূল পেজ
css/style.css        → ডিজাইন
js/main.js            → কোড লজিক (তথ্য এখন content ফাইল থেকে আসে)
content/settings.json  → নাম, ছবি, কন্টাক্ট তথ্য (এডমিন প্যানেল এডিট করে)
content/categories.json → ক্যাটাগরি/সেকশনের তালিকা (এডমিন প্যানেল এডিট করে)
content/portfolio.json → কাজের ডেটা (এডমিন প্যানেল এডিট করে)
admin/                → এডমিন প্যানেল (Decap CMS)
images/uploads/       → আপলোড হওয়া ছবিগুলো এখানে জমা হবে
```
